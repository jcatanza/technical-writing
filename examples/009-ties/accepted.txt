The lists are not trials. Each list is the sequence of codes that the matching code records (`row_codes`). It has one entry per alert, plus one extra entry for each frost event that nobody found.

The two cases have different numbers of entries because the second case has no missed event.

In both cases there are 2 alerts (B and A) and 2 frost events (P1 and P2). All entries use zone 0, so a code of 0 means "an event in zone 0" and -1 means "false alert".

**Case 1: P1 comes first in the list**

1. Alert B comes first. It ties with both events, so the code takes the first one in the list, P1. B claims P1, so its entry is **0**.
2. Alert A comes next. Its best match is P1, which B already claimed. A is a false alert: **-1**.
3. Nobody claimed P2. The code adds one more entry for the missed event: **0**.

The result is [0, -1, 0].

**Case 2: P2 comes first in the list.** B claims P2, so its entry is **0**. A claims P1, so its entry is **0**. The code misses no event. The result is [0, 0].
